# Criterios de Selección y Auditoría de 300 Fuentes de Frontend y Producción Musical

Este documento establece el marco riguroso para la consulta, catalogación y aplicación de 300 fuentes públicas, repositorios de código abiertos y bases de datos de referencia (Frontend, UX/UI, Accesibilidad, Seguridad, Audio Web y FL Studio).

## 1. Categorías del Universo de 300 Fuentes
1. **Design Systems & Frontend Architecture:** 50 fuentes (Tailwind CSS plugins, Radix UI primitives, React 19 patrones, State Management, Zustand, TanStack Query).
2. **Audio Web & Multimedia APIs:** 50 fuentes (Web Audio API specs, Tone.js, Wavesurfer.js, Web MIDI API, decodificación de stems).
3. **Open Source Music Tools & FL Studio Companions:** 50 fuentes (Repositorios de GitHub de organizadores, temas de interfaz, analizadores de espectro, presets de Patcher).
4. **UX/UI Pro, Accesibilidad & Performance:** 50 fuentes (WCAG 2.2 guidelines, Core Web Vitals, Glassmorphism design tokens, microinteracciones).
5. **Seguridad Frontend, Validación y Envelopes:** 50 fuentes (Zod schemas, CSP headers, Sanitización DOMPurify, Rate limiting client-side).
6. **Estándares de Producción y Masterización:** 50 fuentes (LUFS targets, True Peak metering, compresión paralela, vocal tuning workflows).

## 2. Regla de Trazabilidad
Ninguna fuente será incorporada sin su URL oficial, licencia (MIT, Apache 2.0, GPL, etc.) y evidencia de aplicación en el código fuente de DUCK Studio.
